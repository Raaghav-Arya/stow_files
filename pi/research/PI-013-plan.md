# PI-013 implementation plan (before implementation)

1. Read installed extension, security, TUI, keybinding contracts, official plan-mode source and local editor/config. Review pinned public OpenCode plan plugin source and licensing online. Record provenance and reject regex shell safety.
2. Implement independent local state machine and extension adapter under `.pi/agent/extensions/plan-mode/`. Default normal for sessions with no plan history; explicit `/plan` enters. While planning allow only trusted built-in read/grep/find/ls and a local session-only `plan_draft` tool. Block all shell, delegation, unknown/MCP/custom tools and user shell. Do not trust readOnlyHint metadata.
3. Store Markdown plans in custom session entries (no filesystem write exception), with revision and explicit approved-plan snapshot. User can edit/review via built-in editor, approve exact revision explicitly via `/plan approve`, or cancel into a still-restricted planning state. Explicit confirmed `/plan leave` abandons restrictions without claiming approval. No auto model turn on approval.
4. Reconstruct branch-local state; restore any persisted plan/execute state into plan mode requiring renewed approval. Handle tree navigation as well as startup/reload; refuse transitions while busy. Publish read-only versioned event state for footer and policy consumers. Never expose an event/tool to approve.
5. Test adapter offline using a captured API and pure state tests: transition approval/revision/cancellation, branch restoration, denied shell/custom/delegation/nested calls, status events, no shortcut/editor replacement, headless refusal and stale UI races. Run without model calls.
6. Document usage, enable/disable, strict limitations (trusted tool names/extension overrides, arbitrary extension OS operations, existing background processes, session logging, model traffic), remaining live-terminal acceptance and integration decisions.

Conservative decisions: no shortcut registered; propose Ctrl+Alt+P only after actual terminal audit, preserve Shift+Tab. No shell allowlist, no plan file, no progress automation, no delegated planners. Clarification is normal conversation. Already running child processes must be stopped by user before entering; this gate cannot stop them. PI-004 decisions remain independent in execution.
